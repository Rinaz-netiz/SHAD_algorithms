### Решение задачи:
**Идея решения**: жадные алгоритм с сортировкой 
1. Будем хранить массив силы игроков, как структуру `Person` с полями `value` и `index`, чтобы потом востановить ответ.
2. Заметим, что для решения поставленной задачи нам достаточно сравнить сумму двух наименьших элементов с максимальным значением в массиве результатов, так как для остальных элементов условие будет автоматически выполнено, если оно уже выполняется для минимальных и максимального.
3. Отсортируем массив `Person` по полю `value` для создания монотонной последовательности, в которой значения не убывают.
4. Так как массив `Person` теперь монотонен, значит можно воспользоваться идеей двух указателей. Расположим и обозначим их так:
	```cpp
	left = 0;
	right = 2;
	```
5. Будем иметь следующий обход массива для получения правильного ответа:
	1. Двигаем правый указатель вперед.
	2. Проверяем, что условие `Person[left].value + Person[left+1].value >= Person[right].value` выполняется, если нет, то двигаем левый указатель вперед и и проверяем, чтобы `left + 1 < right` (чтобы в команде оставалось минимум 2 игрока)
	3. Если накопленная сумма эффективности команды максимальна, то обновляем ответ и сохраняем правый и левый конец отрезка для восстановления ответа
6. После получения результатов собираем значения на лучшем отрезке в отдельный массив, сортируем его в порядке возрастаня индексов и выводим ответ.

**Сложность по времени:**
```
n - количество элементов в массиве

1. Сортировка изначального массива: O(n * log n)
2. Обход массива двумя указателями: O(2 * n)
3. Получение игроков на лучшем отрезке: O(n)
4. Сортировка ответа: O(n * log n)
```
**Итоговая асимптотика по времени:**  `O(n * log n)`

**Сложность по памяти:**
```
n - количество элементов в массиве

1. Хранение входных данных: O(n)
2. Хранени результата: O(n)
```
**Итоговая сложность алгоритма по памяты:** `O(n)`
